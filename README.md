# Sam Thinks a Lot

**Una aventura sobre decisiones, videojuegos y equilibrio digital.**

Explora la historia de Sam, juega distintos retos y descubre cómo sus decisiones cambian el camino hasta el final.

**Hecho con Processing** · Historia interactiva · Minijuegos · Arcade

</div>

---

## 🎮 ¿Qué encontrarás?

- **Historia interactiva:** escenas, conversaciones y decisiones que conectan los niveles.
- **Retos variados:** penaltis, cocina musical y un arcade de plataformas.
- **Juegos en el celular:** frutas, parejas y pixel art.
- **Progreso y finales:** puntos, recuerdos, guardado y diferentes desenlaces.

## 🚀 Cómo jugar

1. Descarga el repositorio con **Code → Download ZIP** o clónalo:

   ```bash
   git clone https://github.com/Roucks/Sam_thinks_a_lot.git
   ```

2. Abre la carpeta `Sam_thinks_a_lot` en **Processing**.
3. Si Processing lo solicita, instala las bibliotecas **Video** y **Sound** desde **Sketch → Import Library → Manage Libraries**.
4. Ejecuta el sketch con el botón **▶**. El juego se abre en pantalla completa.

> Los controles cambian según la escena o el minijuego. Sigue las indicaciones que aparecen en pantalla.
