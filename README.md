# Sam Thinks a Lot

Videojuego desarrollado en Processing. El archivo principal del sketch es `DigitalBalance_entrega3_AFES_SAPS_ADOC_JPPJ.pde`.

## Ejecutar

1. Abre esta carpeta como sketch en Processing.
2. Instala las bibliotecas **Video** y **Sound** desde el gestor de bibliotecas de Processing si faltan en tu instalación.
3. Ejecuta el sketch. Los recursos del juego están en `data/`.

El repositorio incluye el código fuente, los recursos y la documentación. Las bibliotecas nativas para cada sistema operativo se regeneran al instalar Video y Sound, por lo que no se versionan.
